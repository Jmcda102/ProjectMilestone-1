Glossary

Key Concepts

These seven ideas are the building blocks for understanding how HTTP works and how it has changed over time.

1. HTTP (Hypertext Transfer Protocol)

The set of rules that browsers and servers follow to request and send web content. It is the base of data exchange on the web.

2. Client and Server

The client is the program that makes a request, usually a web browser. The server is the computer that stores the website and sends back responses.

3. Request and Response

A request is a message from the client asking for a resource. A response is the server's reply. It holds a status code, headers, and usually the content.

4. Status Codes

Three digit numbers in every response that show the result. For example, 200 means success and 404 means the page was not found.

5. Headers

Extra lines of information sent with requests and responses. They describe things like the content type, caching rules, and cookies.

6. HTTPS and TLS

HTTPS is HTTP protected by TLS encryption. It keeps data private and confirms the identity of the website with a certificate.

7. Multiplexing and QUIC

Multiplexing, added in HTTP/2, lets many requests share one connection at the same time. QUIC is the newer transport used by HTTP/3 to make connections faster and more reliable.
