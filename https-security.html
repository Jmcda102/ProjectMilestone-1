Topic 3

HTTPS and Security

Plain HTTP sends data as readable text. HTTPS adds encryption so passwords, payments, and personal information stay private while they travel across the internet.

What HTTPS Adds

HTTPS is HTTP sent through a secure layer called TLS (Transport Layer Security). TLS gives three protections:

  • Encryption

    Other people on the network cannot read the data.

  • Integrity

    The data cannot be changed on the way without being noticed.

  • Authentication

    A certificate proves the site is who it says it is.

How a Secure Connection Starts

  1. The browser connects and asks for a secure session.
  2. The server sends its certificate, which is signed by a trusted certificate authority.
  3. The browser checks the certificate.
  4. Both sides agree on keys and start sending encrypted HTTP messages.

Why HTTPS Became the Default

Free certificate services like Let's Encrypt made HTTPS easy for any site to use. Browsers now warn users about plain HTTP pages, and search engines give secure sites a small ranking boost. HTTP/2 is used over HTTPS in all major browsers, and HTTP/3 always includes encryption, so newer HTTP versions and security now go together.
