Topic 2

HTTP Versions

The basic idea of a request and a response has stayed the same since 1991, but each new version made the web faster and able to handle more content.

Timeline Overview

Version by Version

  1. 1991

    HTTP/0.9

    Tim Berners-Lee created the first version at CERN. It had only one method, GET, and could only return plain HTML. There were no headers and no status codes.

  2. 1996

    HTTP/1.0

    HTTP/1.0 added headers, status codes, and the ability to send files other than HTML, such as images. A new connection was opened for every single request, which was slow.

  3. 1997

    HTTP/1.1

    HTTP/1.1 became the standard for almost 20 years. It added persistent connections so one connection could be reused, the Host header so many websites could share one server, and better caching. Its main weakness was that requests on a connection still had to wait in line. This is called head of line blocking.

  4. 2015

    HTTP/2

    HTTP/2 was based on Google's SPDY project. It sends data in binary frames and uses multiplexing, so many requests and responses can travel over one connection at the same time. It also compresses headers to save space.

  5. 2022

    HTTP/3

    HTTP/3 runs on QUIC instead of TCP. QUIC uses UDP and has encryption built in. If one packet is lost, only that stream waits, not the whole connection. It also connects faster and handles network changes better, such as moving from Wi-Fi to cellular data.
